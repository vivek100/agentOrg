# AgentOrg frontend

This directory is the **Next.js** application for [AgentOrg](../README.md): workspace UI, org canvas, API route handlers, Zod contracts, and optional InsForge persistence.

```powershell
cd frontend
Copy-Item .env.example .env.local
npm install
npm run dev
```

See the **repository root [README.md](../README.md)** for features, stack, InsForge setup, and documentation links.
